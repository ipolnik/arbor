# Arbor — сайт мебельной мастерской

Одностраничный каталог для телефонов: товары, контакты, заказ через WhatsApp.

- `index.html` — сайт. Всё содержимое берётся из `content/site.json`.
- `admin/` — панель управления (Decap CMS) по адресу `/admin/`. Вход через GitHub; каждое сохранение — коммит, Netlify сам обновляет сайт.
- `images/uploads/` — фото товаров и логотип.
